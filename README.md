# Studio Zahaa Elegance

Crée un site web élégant et moderne pour un institut de beauté haut de gamme appelé **Studio Zahaa**, situé à Asnières-sur-Seine.

---

## 🎨 Style & Design

- Univers visuel luxueux et épuré : tons beige, ivoire, doré et noir

- Typographie raffinée (serif pour les titres, sans-serif pour le corps)

- Ambiance "spa premium" avec des micro-animations subtiles

- Design responsive mobile-first
